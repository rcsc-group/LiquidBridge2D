# 2D Liquid Bridge

Working implementation for the two-dimensional model of a liquid bridge created between two cylinders held at a fixed distance between them. The key challenge is including contact angle dynamics over embedded solid geometries, as only recently (2024) [implemented in Basilisk](http://basilisk.fr/sandbox/tavares/) and expanded upon in [the associated publication](https://www.sciencedirect.com/science/article/pii/S004579302400149X).
